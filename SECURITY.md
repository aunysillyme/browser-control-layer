# Security

## Protected resources

Process signals require fresh identity and profile ownership proof. The user's
own profile stays untouched. Persistent driver directories are preserved.
Fetched text is untrusted data. URL checks and pinned DNS apply to redirects.
Hooks stay local and run with the host's permissions.

## Private disclosure

Use [Report a vulnerability](https://github.com/aunysillyme/browser-control-layer/security/advisories/new).
Include a synthetic reproduction and affected revision. Keep credentials and
personal data out of public issues. If the route is unavailable, use
[GitHub Support](https://support.github.com/contact).
